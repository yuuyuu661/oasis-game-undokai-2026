# みんなの運動会 2026

9月18日〜21日に開催する3チーム対抗ゲーム運動会の公開タイムテーブル兼、運営編集サイトです。3ステージの並行進行、全24競技の状態、チーム得点、全体進捗を参加者へ表示します。

## 主な機能

- 4日間・3ステージのタイムテーブル表示
- 進行中／遅延／終了のステータス表示と全体進捗
- 3チームの得点と総合順位（運営側でチーム名・得点を編集可能）
- パスワード保護された運営モード
- ドラッグによる開始時刻変更、カード伸縮による所要時間変更
- 競技名、ステータス、参加者向けメモの編集
- PostgreSQLによる編集内容の永続保存（ローカルはJSON保存）

## 環境変数

`.env.example` を参照してください。本番環境では `ADMIN_PASSWORD`、`SESSION_SECRET`、`DATABASE_URL` が必要です。

## 起動

```bash
pnpm install
pnpm run build
pnpm start
```
